# agent-notes

Notes and small scripts from running personal agents across machines
(Tailscale, Yobiru, Grok Bot, etc.).

## Privacy
No auth keys, tokens, private IPs, or message contents in this repo.
Use placeholders like `<PEER>/grok` in examples.

## Layout
```
notes/          # markdown notes
scripts/        # helper scripts (safe to share)
```

## Status
Skeleton — document what you actually set up, week by week.
